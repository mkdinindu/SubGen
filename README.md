# SubGen

Generate `.srt` subtitles from video files using [OpenAI Whisper](https://github.com/openai/whisper) for speech-to-text, with optional translation through [Ollama](https://ollama.com).

SubGen extracts the audio, transcribes it with word-level timestamps, splits the result into readable subtitle chunks, and writes a standard SRT file. It ships with a command-line tool, a Tkinter desktop GUI, and a Google Colab notebook for GPU-accelerated runs.

> **Project background:** This is my hobby project. I designed the tool — its pipeline, features, and behaviour — and the implementation was written entirely with the help of LLM models (AI-assisted coding). The code was generated by LLMs from my design.

## Features

- 🎙️ Speech-to-text with Whisper (`tiny` → `large`)
- 🌍 Automatic language detection or a manually specified audio language
- ✂️ Readable subtitle chunking based on characters per line, max lines, and min/max duration
- ⏱️ Timestamp offset (delay) for syncing subtitles
- 🌐 Optional translation to any language supported by your Ollama model
- 🖥️ Simple Tkinter GUI with live logs
- ☁️ Colab notebook using `faster-whisper` on GPU
- 📝 Output in standard `.srt` format

## Requirements

- Python 3.9+
- [`ffmpeg`](https://ffmpeg.org/) (includes `ffprobe`)
- [`openai-whisper`](https://pypi.org/project/openai-whisper/)
- `tqdm` (optional, enables progress bars)
- [Ollama](https://ollama.com) (optional, only for translation)

A GPU is recommended but not required for the CLI; Whisper will fall back to CPU (slower).

## Installation

### 1. Install system dependencies

```bash
# Debian / Ubuntu
sudo apt update && sudo apt install -y ffmpeg

# macOS
brew install ffmpeg
```

### 2. Create a virtual environment and install Python packages

```bash
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install --upgrade pip
pip install openai-whisper tqdm
```

> **Note:** `openai-whisper` installs PyTorch automatically. For CUDA acceleration, install the appropriate PyTorch build for your system first, then install Whisper.

### 3. (Optional) Set up Ollama for translation

```bash
# Install from https://ollama.com, then:
ollama pull gemma
```

## Usage

### Command line

```bash
python subgen.py <video> [options]
```

Basic example:

```bash
python subgen.py movie.mp4
```

This writes `movie.srt` next to the video.

#### Options

| Option | Default | Description |
| --- | --- | --- |
| `video` | — | Path to the input video file (required) |
| `-o`, `--output` | `<video>.srt` | Output SRT path |
| `--whisper-model` | `base` | Model size: `tiny`, `base`, `small`, `medium`, `large` |
| `--language` | auto-detect | Audio language code, e.g. `en`, `es`, `ru` |
| `--delay` | `0.0` | Offset all timestamps in seconds (negative = earlier) |
| `--min-duration` | `1.0` | Minimum subtitle duration in seconds |
| `--max-duration` | `6.0` | Maximum subtitle duration in seconds |
| `--chars-per-line` | `42` | Maximum characters per subtitle line |
| `--translate` | off | Enable translation via Ollama |
| `--source-lang` | `English` | Source language name |
| `--source-code` | `en` | Source language code |
| `--target-lang` | `Spanish` | Target language name |
| `--target-code` | `es` | Target language code |
| `--ollama-model` | `gemma` | Ollama model used for translation |

#### Examples

High-quality transcription with a specific language and model:

```bash
python subgen.py lecture.mkv --whisper-model large --language en -o lecture.srt
```

Fix subtitle sync by shifting timestamps 1.5 seconds later:

```bash
python subgen.py movie.mp4 --delay 1.5
```

Transcribe Russian audio and translate it to English:

```bash
python subgen.py interview.mp4 --language ru --translate \
  --source-lang Russian --source-code ru \
  --target-lang English --target-code en \
  --ollama-model gemma
```

Tighter subtitles for social media:

```bash
python subgen.py clip.mp4 --chars-per-line 32 --max-duration 4 --min-duration 1.2
```

### Desktop GUI

```bash
python gui.py
```

Select a video, adjust the Whisper and timing settings, optionally enable translation, and click **Generate Subtitles**. The pipeline output is streamed to the log panel.


### Standalone translation

`translate.py` translates a single string and prints the result:

```bash
python translate.py "Hello, world!" --target-lang Spanish --target-code es --model gemma
```

## How it works

1. **Probe duration** — `ffprobe` reads the video length for the progress bar.
2. **Extract audio** — `ffmpeg` converts the audio to 16 kHz mono WAV.
3. **Transcribe** — Whisper transcribes with `word_timestamps=True`.
4. **Chunk** — words are grouped into subtitles while respecting `chars-per-line`, `max-duration`, `min-duration`, and a maximum of two lines.
5. **Offset** — the optional `--delay` is applied to every timestamp.
6. **Translate (optional)** — each chunk is sent to Ollama with a translation prompt, one request per subtitle.
7. **Write SRT** — entries are written in standard `HH:MM:SS,mmm --> HH:MM:SS,mmm` format.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| `ffmpeg not found` | Install ffmpeg and ensure it is on your `PATH`. |
| `openai-whisper not installed` | `pip install openai-whisper` in the active environment. |
| `ollama not found` | Install Ollama from <https://ollama.com> or disable translation. |
| Translation is slow | Each subtitle is a separate model call. Use a smaller model or a more powerful machine/GPU. |
| Out of memory | Use a smaller Whisper model (`tiny` or `base`). |
| Subtitles out of sync | Adjust `--delay` (positive = later, negative = earlier). |
| No word timestamps | Some models/languages produce poor word timing; try a larger model. |

## Notes and limitations

- Translation quality depends entirely on the selected Ollama model and prompt.
- Translations are performed one subtitle chunk at a time, so context across lines is limited.
- The CLI and GUI use `openai-whisper`; the Colab notebook uses `faster-whisper`, which requires separate installation.
- Very long videos can take a significant amount of time to transcribe on CPU.
